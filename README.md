## v7.0.53 · 定名「骨肉法」

**定性：立法哲学正式定名——手册给的是骨架，保证的是骨架，修的也是骨架，血肉随模型自己长。**

- 配套词典：骨肉问句（换模型换轮次答案会不会变）／骨肉六问（歧词·并存·误扩·悬空·诱导·句位）／骨肉五刀（消歧·归一·点名·禁改令·同构明示）／进出两尺（血肉不立法·已治本之堵不留册）
- 全册一名到底（含旧修订表条目同步改净，防两名并存）

## v7.0.50–52 · 骨架血肉哲学入册＋减字刀

**定性：法典有了退出机制——条款不再只进不出。**

- 「骨架保下限、血肉出上限」刻入《作者的话》：血肉是价值产区，立法即封矿
- 新尺子回量 7.0.42 前老法：三处纯堵口删冗余；锚点自检治本（只列涉及维度、未涉及一字不提）
- 原则一双入册：不执行的要求不留册（认知税）＋已治本的行为禁令不留册

## v7.0.42–49 · 首轮输出格式七版立法

**定性：首轮三大件（核心观察·检索指引·下一步建议）版式从零钉到稳——七版连改，全部来自实测反馈。**

- 组件序定死：大字标题→分隔条→三式代码块→检索/导出规则并列→尾注→锚点→日志
- 同构明示法两案：【核心观察】标题两胎全丢，根因＝「总题」歧义＋双名并存＋禁令误扩——与【检索指引】同构后根治
- 加粗对象点名（治文字版剥标签后目标悬空）、禁罗列概念簇、普查收窄判定底线
- 「下一步建议」升格一级段标题——级别词须全称，一个「小」字即降格

## v7.0.40 · 追问退出首轮——物料依赖式轮次结构

**定性：用户主导的最大重构——首轮零提问，次轮才吃物料。**

- 首轮固定三件：核心观察｜普查检索式三式｜写作入口双路径（正式＝报数→判定→导出→审计；模拟＝说直接执行）
- 停笔纪律由「物料依赖」结构性替代——AI 想合并轮次也无料可造
- 追问收窄功能归次轮；「基于未追问信息推断」标注退役

## v7.0.38–39 · 跨模型实测＋执行版回归

**定性：换模型不换规矩的第一次全面压测；注意力稀释定论坐实。**

- 双模型实测驱动：知网加号语法订正（OR 连簇实测报错）、裸词警示收回（「姜」炸库 12,741 条）、汇编工序立法（体检/答辩受检对象＝汇编全文）
- 「⚡ 复制执行版」回归（v7.0.29 曾撤）：同一模型，完整版无视册内订正、执行版精准送达——长上下文注意力稀释是结构性根因
- 预印本 DOI 验真翻案：当年判「大概率幻觉」的吴宇团队两篇（2024 产热＋2026 肺模型）全部实锤为真
