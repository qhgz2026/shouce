## v6.8 · 双向对抗答辩诞生

## v7.0.25 · 过程化改造（八卷实测驱动）

**定性：把质检从"末端自检"改为"过程控制"——治未病。**

- 数字与出处同行（即时标引，取代事后对账；防八卷 14 处对账违规）
- 计数定义收紧：观点、结论、分歧的个数不构成计数
- 背景线索区归区细化：评论性批判源、转引整理文档入区并标性质
- 一级验证边界提醒并入出口五查（第六查，闸口代替自觉）
- 分段局部自检取代"整份作废重出"（自回归模型架构上无法撤回，回滚一段可行、回滚全卷不可行）
- 工序骨架限定结构性段落（清单／验证／五查；核心观察保持连贯行文豁免）
- 竞争预判窗口从宽、依据必留一句
- 五查逐条带实据、与分段自检分工（完整性／一致性）
- 锚点增追问禁区（不问作者本人健康、体质、舌脉）

## v7.0.26 · 总纲·实绩栏·减法

**定性：确立"选题分析的正确性为第一要务"的最高原则；自证体系登场（后于 v7.0.31 整体撤销）。**

- 【总纲·选题急救】入写作规格引言位：红线（破立／验证真实性／情报完整性）／辅助／兜底三层分清；手册其余功能不受约束
- 五查实绩栏：完成项勾选举实据、未完成项留空（留空即诚实信号）、限制必标、勾选不作真实性担保、对账终审归 5.1
- 受限环境条款：无联网验证不可用时，不得输出任何选题判断，仅交付骨架与指引并标"未验证"
- 假 DOI 防御：无把握宁可不给，仅著录刊名年卷期页（tcmjc.com 污染案）
- 推荐所据核心基线数据须有出处；修正依据限学术来源；覆盖轻核对；挂锚锚号范围校验
- 工序骨架限受限环境默认启用（联网不强制）
- 同日增补：检索式减法（仅推荐角度给检索式）＋文献清单简式（非推荐角度著录从简）

## v7.0.28 · 冲突裁决与豁免写死

- 追问时点固定（核心观察后、清单前）＋未答追问标注「以下基于未追问信息推断」

## v7.0.32 · 三段式前奏·二段式·防线收束

**定性：认知预算分摊到两轮；三层防线（自证／机器互查／人查）收束为一层。**

- 二段式急救流程：首轮核心观察＋追问即停；次轮清单→验证→推荐→规格
- 工序审计退休：两轮额度下漏项率大降＋与 5.1 重复＋真实使用零触发
- 「协议在位检查」退休（同病：备而不用即认知税）
- 三层防线收束为"人查机器"——每层的撤销都有实测判例背书
- 翻车档案：DS 首测把首轮执行三遍（追问循环无终止条件）；Kimi 一次通过——轮次契约补丁（回答即触发次轮／追加追问限一轮须明示"最后一问"／禁止重复核心观察）**列为已知待办，截至本版未施工**

## v7.0.33 · 三段式·角度深挖·审稿前置

**定性：最后一件不是减法，是填空——从"选对题"一路护到"方案成型"。**

- 三段式执行：首轮核心观察＋追问 → 次轮清单／验证／推荐／规格（末停笔待确认角度）→ 三轮角度深挖
- 「角度深挖」第六枚直达口令，四件交付：
  ①核心文献精读清单（≤10 条，逐条注明"该文为你提供什么"）
  ②方法学设计包（设计／样本量／纳排／统计／质控）＋数据采集表（字段级：变量／类型／编码／采集方式／用途说明；必需／可换／可选三级刚性；差异须说明取舍理由）＋量表直供（直接指定，附选用依据与可替换项）
  ③创新点论证（与最近文献差异化对照＋审稿人最可能三问与回应口径）
  ④写作路线图（三级提纲＋每节数据需求＋周期估计）
- 角度确认单字符指代：次轮后仅回复数字即深挖该角度；聊过几轮想换角度用完整口令「角度深挖 N」
- 次轮末显式提示确认方式（输出端提醒义务）
- 立意入册："依据说明即审稿问答前置"——必问题在设计阶段答
- 伍篇结尾增"审稿前置"哲学段：自我答辩、三问三答、体裁核对、取舍理由，处处是预演审稿——"审稿不是写作之后的事故，而是写作之前的输入"
